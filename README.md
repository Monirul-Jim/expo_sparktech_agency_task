# SparkTech Agency Task (Expo + React Native)

[![Author: Monirul Jim](https://img.shields.io/badge/Author-Monirul%20Jim-blue?style=for-the-badge)](https://github.com/Monirul-Jim)
[![Role: React Native Developer](https://img.shields.io/badge/Role-React%20Native%20Developer-brightgreen?style=for-the-badge)]()

A mobile application built using **Expo**, **React Native**, and **Redux Toolkit** with user authentication, profile details, and profile image update support.

---

## 🚀 Features

- Login & Signup Authentication
- JWT Token handling with Redux
- Profile view and edit
- Upload & update profile image
- RTK Query for API calls
- React Hook Form for form handling
- Task Management: Create, Read, Update, Delete (CRUD) tasks
- Onboarding screens, splash screen, and adaptive icons
---

## 🛠️ Tech Used

- **React Native / Expo**
- **Redux Toolkit + RTK Query**
- **React Hook Form**
- **Expo Router**
- **Expo Image Picker**
